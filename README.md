# Terminal Web

A free desktop browser for Windows that shows the whole web the way a terminal from the 80s
would: one font, one colour (you pick it), and no clutter.

**Website:** https://terminalweb1984.netlify.app/

## Download

Get the installers from the [Releases](https://github.com/leiadigitalmediainc/The_Terminal_Web_Downloads/releases) page:

- **TerminalWeb-Setup.exe** - Terminal Web, the browser
- **TerminalWebBuilder-Setup.exe** - Terminal Web Builder, for making your own sites

Windows may say it doesn't recognise the app the first time. Click **More info**, then
**Run anyway**.
